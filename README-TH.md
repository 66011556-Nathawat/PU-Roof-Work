## 1. วัตถุประสงค์และภาพรวมระบบ (System Overview)

ระบบ **PU Roof Works Decision Hub** ถูกสร้างขึ้นเพื่อตอบสนองต่อกระบวนการทำงานจริงของโรงงานผลิตหลังคาเมทัลชีทในประเทศไทย:
1. **แก้ปัญหาความล่าช้าของข้อมูล**: ผู้บริหารไม่ต้องรอปิดงบสิ้นเดือน สามารถเห็นยอดขายสะสม (MTD) และความเร็วการขาย (Pace) ได้ทุกวัน
2. **รองรับ 3 ไฟล์ CSV จากโปรแกรมบัญชี Express โดยตรง**:
   - **ขายเงินสด (Cash Sales)**: สำหรับลูกค้าเงินสดและช่างรายย่อย
   - **ใบกำกับสินค้า / ขายเชื่อ (Credit Invoices)**: สำหรับผู้รับเหมาโครงการ พร้อมระบบวิเคราะห์อายุหนี้ (AR Aging: 0-30, 31-60, 61-90, 90+ วัน)
   - **ใบรับมัดจำ (Deposit Receipts)**: สำหรับเงินมัดจำล่วงหน้าค่าสั่งผลิตแผ่นหลังคา PU สเปกพิเศษ
3. **ระบบคิวงานผลิตและจัดส่ง (Job Delivery Tracker)**:
   - เชื่อมโยงงานรีดลอนและติดฉนวน PU เข้ากับคิวรถจัดส่งสินค้าถึงหน้างานแบบเรียลไทม์
   - 4 ขั้นตอนสายการผลิต: `รอรีดลอน` → `กำลังติด PU` → `พร้อมจัดส่ง` → `จัดส่งเรียบร้อย`
   - แสดงเลขที่ Job, ชื่อลูกค้า, สถานที่จัดส่ง, ความยาวรวม (เมตร), ช่างผู้รับเหมา และเบอร์ติดต่อ
4. **ระบบสิทธิ์และความปลอดภัย (RBAC)**:
   - **CEO (ผู้บริหารสูงสุด)**: ปลดล็อกด้วยรหัสผ่าน Master PIN **\`1234\`** (ระบุไว้ในเอกสาร GitHub ฉบับนี้เพื่อการบริหารระบบ) มีสิทธิ์ 100% ครอบคลุมทุกระบบ, อนุมัติส่วนลดพิเศษกรณี Margin ต่ำกว่า 20%, และออกข้อสั่งการถึง Admin
   - **Admin (ผู้ดูแลระบบ)**: ควบคุมการนำเข้าไฟล์ Express และตอบกลับข้อสั่งการของ CEO
   - **ฝ่ายขาย (Sales)**: ออกใบเสนอราคา (Track B) และดูรายการลูกหนี้ของตนเอง
   - **ฝ่ายคลังและจัดส่ง (Warehouse)**: ตรวจสอบวันครอบคลุมสต็อก (DoC), จุดสั่งซื้อซ้ำ (ROP), และคิวจัดส่ง
   - **ฝ่ายบัญชี (Accounting)**: ควบคุมยอดลูกหนี้และกระทบยอดเงินมัดจำ

## 2. การทำงานของระบบคิวงานผลิตและจัดส่ง (Production Delivery Workflow)

โมดูล **คิวงานผลิตและจัดส่ง (Job Delivery Tracker)** ถูกออกแบบมาเพื่อแก้ปัญหาคอขวดระหว่างฝ่ายขาย ฝ่ายผลิตหน้าโรงงาน และทีมรถขนส่ง:

### 4 ขั้นตอนหลักของสายการผลิต (Manufacturing Pipeline)
1. **1. รอรีดลอน (Roll Forming Pending)**:
   - งานได้รับคำสั่งซื้อและตรวจเช็กสเปกม้วนคอยล์เหล็ก (ความหนา 0.35, 0.40, 0.47 มม., สีอลูซิงค์ / สีเคลือบ)
   - ยกม้วนเหล็กขึ้นแท่น De-coiler และตั้งค่าเครื่องรีดลอนตามแบบ (ลอน 760 มาตรฐาน, ลอนสเปน, ลอนผนัง)
2. **2. กำลังติด PU (Applying PU Foam / Polyurethane Lamination)**:
   - เข้าสู่เครื่องฉีดสารเคมีโพลียูรีเทนโฟมความหนาแน่นสูง (PU Rigid Foam ความหนา 1 นิ้ว หรือ 2 นิ้ว)
   - ปิดทับด้วยแผ่นอลูมิเนียมฟอยล์กันความร้อนหรือชีท PVC ภายใต้อุณหภูมิและแรงดันที่ควบคุมอย่างแม่นยำ
3. **3. พร้อมจัดส่ง (Ready to Ship / Staged at Dispatch Bay)**:
   - ตัดความยาวตามระยะหน้างานจริง (เช่น 6.00 ม., 8.20 ม., 12.00 ม.)
   - มัดรัดแผ่นหลังคา ติดป้ายหมายเลขงาน (Job No.) ตรวจสอบความถูกต้องตาม QC Sheet และจัดเรียงขึ้นรถบรรทุก 6 ล้อ / 10 ล้อ
4. **4. จัดส่งเรียบร้อย (Delivered / Signed Site Handover)**:
   - ขนส่งถึงพิกัดหน้างานก่อสร้างของลูกค้า
   - ช่างติดตั้งหรือผู้รับเหมาหน้างานตรวจรับและลงนามในใบส่งของ เจ้าหน้าที่เปลี่ยนสถานะเป็น "จัดส่งเรียบร้อย"

### สิทธิ์การใช้งานโมดูลจัดส่ง
- **ฝ่ายคลังและจัดส่ง (Warehouse)**: เป็นผู้รับผิดชอบหลัก สามารถเปลี่ยนสถานะของแต่ละคิวงานได้ทันทีผ่าน Dropdown
- **ผู้ดูแลระบบ (Admin) & ผู้บริหาร (CEO)**: ดูภาพรวมจำนวนรถที่กำลังเดินทางและสั่งการแก้ไขข้อติดขัด
- **ฝ่ายขาย (Sales)**: ตรวจสอบวันที่นัดส่งมอบและเบอร์ช่างหน้างานเพื่อประสานงานลูกค้า

## 2. การคำนวณทางคณิตศาสตร์ที่ผ่านการตรวจสอบแล้ว (Verified Formulas)

1. **สูตร Run Rate รายเดือน**:
   $$\text{Run Rate} = \left(\frac{\text{ยอดขายสะสม MTD}}{\text{จำนวนวันทำงานที่ผ่านมา}}\right) \times \text{จำนวนวันทำงานทั้งเดือน} \times \text{ตัวคูณฤดูกาล}$$
   - ตัวอย่างทดสอบ: ยอด 500,000 บาท, ผ่านไป 10 วัน, มี 22 วันทำการ = **1,100,000 บาท** (ผ่านเกณฑ์ ✅)

2. **สูตรวันครอบคลุมสต็อก (Days of Cover - DoC)**:
   $$\text{Days of Cover} = \frac{\text{สต็อกคงเหลือ}}{\text{อัตราการใช้งานเฉลี่ยต่อวัน}}$$
   - หาก DoC > 90 วัน ระบบจะแจ้งเตือนเป็นรายการผลักดันขาย (Push List) อัตโนมัติ (ผ่านเกณฑ์ ✅)

3. **สูตรจุดสั่งซื้อซ้ำ (Reorder Point - ROP)**:
   $$\text{Reorder Point} = (\text{อัตราใช้งานต่อวัน} \times \text{ระยะเวลารอคอย Lead Time}) + \text{สต็อกปลอดภัย Safety Stock}$$
   - แจ้งเตือนเมื่อสินค้าถึงเกณฑ์ต้องเปิด PO สั่งคอยล์เหล็กหรือเคมี PU เพิ่มทันที (ผ่านเกณฑ์ ✅)

4. **เกณฑ์กำไรขั้นต่ำของใบเสนอราคา (Profit Margin Guardrail)**:
   - อัตรากำไรขั้นต่ำปลอดภัยคือ **20%**
   - หากราคาขายทำให้กำไร < 20% ระบบจะแสดงคำเตือนสีแดง และต้องใช้รหัสผ่าน CEO **\`1234\`** ในการอนุมัติข้อยกเว้นเท่านั้น (ผ่านเกณฑ์ ✅)

## 3. ไฟล์ทางลัดสำหรับดับเบิลคลิกเปิดใช้งานทันทีในโฟลเดอร์ (1-Click Launchers & Shortcuts)

ผู้ใช้งานและทีมงานสามารถเปิดเข้าสู่ระบบได้ทันทีโดยไม่ต้องเปิด Terminal ด้วยไฟล์ทางลัดที่เตรียมไว้ในโฟลเดอร์หลัก:

| ไฟล์ทางลัด | ระบบปฏิบัติการ | การทำงาน |
| :--- | :--- | :--- |
| **`OPEN_APP.html`** | ทุกระบบ (Windows, Mac, Linux) | พอร์ทัลเปิดแอปพลิเคชัน พร้อมปุ่มเข้าใช้งานแบบออนไลน์ และ Localhost |
| **`OPEN_APP.url`** | Windows | ชอร์ตคัตอินเทอร์เน็ต ดับเบิลคลิกเพื่อเปิดระบบในเว็บเบราว์เซอร์เริ่มต้นทันที |
| **`START_APP.bat`** | Windows | ไฟล์แบตช์สคริปต์ รันโลคอลเซิร์ฟเวอร์และเปิดหน้าต่างเบราว์เซอร์อัตโนมัติ |
| **`START_APP.command`** | macOS / Linux | ไฟล์คำสั่งสคริปต์ ดับเบิลคลิกเพื่อเริ่มระบบและเปิดเบราว์เซอร์อัตโนมัติ |
